# Обработка динамического массива (new/delete)

Учебный проект для освоения работы с динамической памятью в C++.

## Возможности
- Создание динамического массива через `new int[N]{}`
- Функция `process`, принимающая ссылку на указатель (`int*&`)
- Поиск первого отрицательного элемента
- Пересоздание массива с корректным освобождением старой памяти
- Демонстрация безопасного поведения через `nullptr`

## Требования
- Компилятор с поддержкой C++14
- Стандарт: **C++14**

## Сборка и запуск
Команда компиляции: g++ -std=c++14 -O2 -Wall 1_2_laba.cpp -o 1_2_laba.exe
Запуск: .\1_2_laba.exe

## Ключевые моменты
- `int*& arr` — ссылка на указатель, позволяет изменить сам указатель
- `delete[]` перед перенаправлением указателя — избегаем утечек памяти
- `arr = nullptr` после `delete[]` — избегаем dangling pointers
- Проверка `if (arr != nullptr)` перед обращением
